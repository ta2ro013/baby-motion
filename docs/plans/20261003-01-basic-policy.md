## 初期スコープ

最初の技術的マイルストーンは、赤ちゃんの動き(特に寝返り)の動画に対して、姿勢推定が十分な信頼性で機能するかを検証することです。

### PoC の流れ

```text
赤ちゃんの動画
   ↓
フレーム抽出
   ↓
姿勢推定
   ↓
キーポイント追跡
   ↓
動きの特徴量
   ↓
可視化 / 分析
```

## アーキテクチャ(予定)

- iOS: Swift / SwiftUI
- バックエンド: Python / FastAPI
- 動画解析: 未定(MediaPipe、MoveNet、Apple Vision など)
- ストレージ / クラウド: 未定
- AI コメント: 構造化された動き解析結果をもとに LLM で生成

## 開発フェーズ

1. 姿勢推定の PoC
2. モーション解析
3. バックエンド API
4. iPhone MVP
5. AI コメント生成
6. 成長の可視化
7. タイムラインと過去記録との比較

## プライバシー

このリポジトリには、実際の赤ちゃんの写真・動画、個人情報、認証情報、本番データを含めてはいけません。

開発・テストには、合成データ、または機微でないことが明確なサンプルデータを使用してください。
