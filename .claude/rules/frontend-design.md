# デザインルール（フロントエンド / UI）

UI・フロントエンドの実装やリデザインを行う際は、**taste skill（`design-taste-frontend`）を使う**こと。
Claude の既定スタイル（いわゆる "AI slop": Inter フォント + 紫グラデ + 均一な3カード配置など）に
流されず、taste skill が示すデザイン方向づけに従う。

## 適用範囲

- 新規の画面・コンポーネント作成
- 既存 UI のリデザイン・見た目の変更
- スタイル（CSS / Tailwind 等）の調整

バックエンドのみの変更には適用しない。

## 進め方

1. コードを書く前に、taste skill に沿って**デザインの方向性（目的・トーン・制約・差別化ポイント）を先に固める**。

2. 大きめの UI（新規画面・主要フローのリデザイン）は、方向性の段階で一度ユーザーに共有し、合意してから実装に入る。可能であれば、HTML / CSS / Tailwind などでの一部分を作って、ユーザーに見せて方向性を確認する。

3. 実装は Next.js（App Router）と、下記のプロジェクト固有指定に沿わせる。
